# 引き継ぎメモ:科学館 謎解きイベント企画

作成日: 2026年11月13日
このメモは、別のセッションで企画の続きをするための引き継ぎ資料です。新しいセッションの最初に、このメモと下の「資料一覧」のファイルを読んでもらってください。

## 1. 企画の概要

科学館の展示フロアを使った、子ども向けの周遊型謎解きイベント。

- **タイトル(仮)**: 月へ行く合言葉をさがせ! 〜科学探偵団と宇宙の博士〜
- **ストーリー**: 宇宙飛行士の博士から届いた「月へ行くロケットの合言葉」が6つにバラバラになった。子どもたちが「科学探偵」として展示をめぐり、6文字を集める。
- **合言葉**: 「つきにいこう」(6問で1文字ずつ集める)

## 2. 依頼者から聞いた条件(確定)

| 項目 | 内容 |
|---|---|
| 対象 | 小学校低学年〜 |
| 参加形態 | グループ・個人どちらでも参加可 |
| 参加人数 | 1日500名の予定 |
| スタッフ | 受付2名、フロアスタッフ各階2名(固定配置ではなく巡回) |
| 開催期間 | 令和9年度ゴールデンウィーク中の5日間 |
| 形式 | 紙の謎解きシートを受付で渡し、展示場を周回 |
| 所要時間 | 60分程度 |

### 展示の内容
- **2階**: 宇宙コーナー(宇宙に関する知識、ロケット紹介、月の見え方、惑星での体重変化)、放電実験室、ダイナミックワーカー(力学を利用して鉄球を高いところからさまざまな場所へ移動させる)、光のミックスライト(光の三原色)、音の実験、脳の仕組みと視覚の不思議、テコの原理、ジャイロ効果
- **3階**: 化石の展示、マイクロスコープ、デジタルコンテンツ、日本のノーベル賞受賞者のパネル展示、錯覚を利用した展示

## 3. 設計の方針(依頼者が「たたき台としていい感じ」と了承済み)

1. **待たなくても解ける**: 答えは「見る・読む・数える」で分かる。装置の操作は任意。
2. **スタッフに頼らない**: ヒントはシートに印刷(ヒント1は問題の横、ヒント2は裏面)。
3. **自分で答え合わせができる**: 各問題の「あんごうひょう」で答えを文字に変える。間違った答えには別の文字を割り当ててあり、合言葉が言葉として読めれば全問正解。受付は合言葉を見るだけ。
4. **混雑分散**: 解く順番は自由。スタート位置の違うA/B/C版のシートを順番に配る。
5. **低学年向け**: ふりがな付き、文字は少なめ。

## 4. 6問の構成(第1稿)

| 謎 | 階 | 展示 | 内容 | 答え → 文字 | 状態 |
|---|---|---|---|---|---|
| ① | 2F | 惑星での体重 | 体重24kgの探偵は月で何kg? | 4kg → つ | 展示の表記を要確認 |
| ② | 2F | 月の見え方 | 月カードを細い順に並べる | 「すきま」の真ん中 → き | 導入文を要調整 |
| ③ | 2F | 光のミックスライト | 赤+緑の光は何色? | 黄色 → に | 展示で確認できるか要確認 |
| ④ | 2F | ダイナミックワーカー | 鉄球の道にある物の数を数える | 3こ(仮) → い | **数える対象と答えが未確定** |
| ⑤ | 3F | 化石の展示 | いちばん古い生き物は? | 三葉虫(仮) → こ | **展示にある化石へ差し替えが必要** |
| ⑥ | 3F | 錯覚の展示 | 2本の線の長さをくらべる(ミュラー・リヤー錯視) | 同じ長さ → う | シートに図を印刷 |

ボーナスミッション(任意・裏面): 放電、音、テコ、ジャイロ、脳と視覚、マイクロスコープ、ノーベル賞パネル。

詳しい問題文・ヒント・あんごうひょうは、問題案のファイルにあります。

## 6. 未決定事項

### 依頼者に記入・決定してもらう項目(企画書に【記入】と書いた箇所)
- 館名・部署、担当者
- 開催日と開催時間
- 参加費(入館料のみか、別料金か)
- 予算と費用の見積もり
- 景品(探偵バッジ)の素材と仕様
- ピーク日に受付を増員するか
- 広報の方法と時期

### 企画書に入れた仮の数字(前提が変われば見直す)
- 同時に回る人数: 開館時間を9:30〜17:00と仮定し、平均約67名、ピーク時100〜130名
- シートの印刷枚数: 3,000枚(延べ2,500名+予備20%、A/B/C版 各1,000枚)
- バッジ: 2,000個(完走率70%と仮定)

### 現地確認が必要な項目
- ④ ダイナミックワーカー: 数える対象(2〜5個で、装置が止まっていても見えるもの)と答え
- ⑤ 化石: 展示にある3種類と、パネルの年代表記
- ① 惑星での体重: 月の表記が「6分の1」か「0.17倍」などか
- 全問を実際に歩いて、60分に収まるか、低学年が読めるか

## 7. 次にやること(候補)

1. 展示の写真や名前の一覧をもらい、④と⑤の問題を確定する
2. 謎解きシートのレイアウトを作る(A/B/C版、ふりがな付き)
3. 企画書の【記入】箇所を埋めて完成させる
4. 試験運用の計画を立てる
